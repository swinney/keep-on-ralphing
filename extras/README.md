# extras/ — unsupported, preserved

These are **experimental, unsupported** scripts kept for reference. They are not
part of the harness's supported surface, not wired into the base image or the
plugin, and not covered by the kit tests.

- `fanout.sh`, `fanout-land.sh`, `fanout-status.sh`, `m10-tribes.txt` — a
  parallel multi-clone "fan-out" runner from the original *keep-on-the-borderlands*
  build (its M10 milestone). Project-specific and unproven beyond that one use.
- `fanout-harness.md` — the spec that described it.

If a future project genuinely needs parallel fan-out, promote this into a real,
tested capability then. Until then it lives here, out of the way.
